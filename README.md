# Marca Personal con IA — Perfil Forense

Taller de Relevo. Diagnóstico de perfil DISC a partir de evidencia conversacional
real, no de un test de autopercepción.

**Beneficio para quienes siguen a [@relevo.academy](https://instagram.com/relevo.academy)**,
como cortesía del Cripto Latin Fest.

## Contenido

- **Presentación** — 10 diapositivas: qué es un diagnóstico frente a un test, qué
  mide DISC, por qué la evidencia gana al autorreporte, y qué valor genera cuando
  la IA conoce tu perfil.
- **Los 3 Prompts** — listos para copiar y correr en una sola conversación.
- **Vocabulario** — 11 términos sin jerga.

## Identidad

Sigue el `RELEVO_MANUAL DE IDENTIDAD`:

| Token | Valor |
|---|---|
| Negro | `#050505` |
| Carbón | `#131415` |
| Turquesa | `#1FE6AB` |
| Gris | `#A7ABAF` |
| Títulos y cuerpo | Instrument Sans |
| Datos y prompts | IBM Plex Mono |

**El ámbar `#E8A33D` se usa solo para advertencias.** Esa restricción es lo que
hace que la marca lea profesional; si se usa para decorar, deja de alertar.

> Nota: el manual trae dos erratas. El hex del gris figura como `#67A6A3` pero sus
> propios valores RGB (167, 171, 175) dan `#A7ABAF`. Y la tipografía aparece como
> "Instrumental Sans" cuando la real es **Instrument Sans**.
